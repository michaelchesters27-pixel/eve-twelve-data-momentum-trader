EVE TWELVE DATA MOMENTUM TRADER v1.03
====================================

THIS IS A REAL TRADING EA. USE A HEDGING DEMO ACCOUNT ONLY.

UPDATE THE EXISTING GITHUB REPOSITORY
-------------------------------------
1. Replace the complete contents of the current GitHub repository with this project.
2. Commit the replacement. Railway redeploys the existing service.
3. Do not change the existing Railway variables.
4. v1.03 starts a clean statistics sample under the built-in v103 data namespace.
5. Remove v1.01 from the MT5 chart.
6. Compile and attach mt5/EVE_Twelve_Data_Momentum_Trader_v1.03.mq5.
7. Use the same Railway URL and BOT_TOKEN.

NO NEW RAILWAY VARIABLES ARE REQUIRED
-------------------------------------
Existing variables remain valid. Optional overrides are available but should be left at defaults initially:
BREAKOUT_CONFIRM_MS=900
BREAKOUT_LOOKBACK_MS=10000
BREAKOUT_EXCLUDE_MS=1200
BREAKOUT_MIN_ATR=0.015
BREAKOUT_PERSISTENCE_MIN=0.68
BREAKOUT_EFFICIENCY_MIN=0.48
BREAKOUT_TICK_EXPANSION_MIN=1.10
DATA_NAMESPACE=v103

MT5
---
MetaEditor must show 0 errors.
Attach v1.03 to ONE XAUUSD M1 chart on a hedging demo account.
Keep Algo Trading enabled.
Do not run v1.01 and v1.03 together.

WHAT CHANGED
------------
- No confirmed breakout = no trade.
- Compression = no trade until a closed expansion.
- Breakout must persist for at least 900 ms.
- Scout must be at least 0.10 ATR favourable before any continuation order.
- REST data refreshes only after candle closes and excludes the live forming candle.
